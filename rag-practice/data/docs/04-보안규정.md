# 누리테크 정보보안 규정

## 계정 및 인증

모든 사내 시스템은 SSO를 통해 접근하며 2단계 인증(2FA)이 필수입니다.
비밀번호는 최소 12자 이상, 영문 대소문자·숫자·특수문자 중 3종류 이상을 포함해야 하며
90일마다 변경합니다. 최근 5회 사용한 비밀번호는 재사용할 수 없습니다.

## 기기 관리

업무용 노트북은 디스크 전체 암호화와 화면 잠금(5분)이 강제 적용됩니다.
개인 기기로 사내 자원에 접근하려면 MDM 등록이 선행되어야 합니다.
기기 분실 시 즉시 보안팀(security@nuritech.example)에 신고해야 하며,
보안팀은 신고 접수 후 30분 이내에 원격 초기화를 수행합니다.

## 데이터 취급

고객 개인정보는 등급 A로 분류되며 운영 데이터베이스 외부로 반출할 수 없습니다.
분석 목적으로 사용할 때는 반드시 가명처리된 데이터셋을 사용합니다.
등급 A 데이터에 대한 조회 이력은 전량 기록되며 분기마다 감사합니다.
소스 코드는 등급 B로, 사내 Git 서버 외부 저장소에 업로드할 수 없습니다.

## 외부 서비스 사용

새로운 SaaS 도구를 업무에 도입하려면 보안팀의 사전 검토가 필요합니다.
검토 요청은 보안 포털에 등록하며 통상 5영업일이 소요됩니다.
생성형 AI 도구에 등급 A 데이터를 입력하는 것은 금지되어 있습니다.
사내 승인된 AI 도구 목록은 보안 포털의 '승인 도구' 페이지에서 확인할 수 있습니다.

## 사고 신고

보안 사고가 의심되면 즉시 보안팀에 신고합니다.
신고자는 선의로 신고한 경우 어떠한 불이익도 받지 않습니다.
피싱 메일로 의심되는 경우 첨부파일을 열지 말고 신고 버튼을 사용해 보고합니다.
